# セルフアチーブ WordPressテーマ インストール手順書

本パッケージは、セルフアチーブ（selfachieve.jp）の新規サイトをWordPress化するためのテーマファイル一式です。
以下の手順に従って、テスト環境（htmlacheive.com）へのインストールおよび設定を行ってください。

## 1. テーマのインストールと有効化

1. WordPress管理画面の「外観」>「テーマ」を開きます。
2. 「新規追加」>「テーマのアップロード」をクリックします。
3. 本パッケージ（`selfachieve_theme.zip`）を選択し、「今すぐインストール」をクリックします。
4. インストール完了後、「有効化」をクリックします。

## 2. 必須プラグインのインストールと有効化

以下のプラグインをインストールし、有効化してください。

- **Advanced Custom Fields PRO (ACF Pro)**
  - ※オーナー様の承認後、ライセンスを購入してインストールしてください。
- **Contact Form 7**
- **All in One SEO**
  - ※既存サイトのデータを引き継ぐため、Yoast SEO等への乗り換えは行いません。
- **Custom Post Type UI** (任意：コードで定義済みですが、管理画面から微調整したい場合)

## 3. パーマリンクの設定

既存サイトのSEO評価を引き継ぐため、パーマリンク設定を必ず以下のように変更してください。

1. 「設定」>「パーマリンク」を開きます。
2. 「カスタム構造」を選択し、以下のタグを入力します。
   `/%category%/%postname%/`
3. 「変更を保存」をクリックします。

## 4. ACFフィールドグループのインポート

テーマ内の `inc/acf-fields.php` にPHPによる定義の雛形が含まれていますが、管理画面から柔軟に編集できるよう、ACFのインポート機能を使用することを推奨します。

1. 「カスタムフィールド」>「ツール」を開きます。
2. 「インポート」機能を使用して、必要なフィールドグループ（お客様の声、制作実績）を作成してください。
   - ※定義の詳細は「カスタムフィールド定義書」を参照してください。

## 5. Contact Form 7 の設定

1. 「お問い合わせ」>「新規追加」を開きます。
2. テーマ内の `inc/cf7-form.txt` の内容をコピーし、フォームの編集画面に貼り付けます。
3. 保存後、生成されたショートコード（例：`[contact-form-7 id="1234" title="お問い合わせフォーム"]`）をコピーします。
4. テーマ内の `page-contact.php` を開き、ショートコード部分を実際のIDに書き換えて保存します。

## 6. 既存データの移行

1. 既存サイト（selfachieve.jp）から、コラム・制作実績・お客様の声・お知らせのデータをエクスポートします。
2. テスト環境（htmlacheive.com）へインポートします。
3. インポート後、各記事のURL（パーマリンク）が既存サイトと完全に一致していることを確認してください。

## 7. 動作確認

以下の点を確認し、問題がなければディレクターへ報告してください。

- 全ページの表示崩れがないこと（特にスマホ表示）
- 既存データのURLが完全に維持されていること
- お問い合わせフォームからテスト送信が正常に動作すること
- All in One SEOのメタ情報（タイトル・ディスクリプション）が正しく出力されていること

---
以上でインストールと設定は完了です。
